# `src/physics` — физическое ядро (Stage 6 / M1)

Без зависимостей, детерминированное. Не подключено к существующим калькуляторам, TechDoc, TEA и Equipment Selector.

## Что реализовано
- Точная рациональная арифметика на BigInt (`exact`): значение считается точно, округляется один раз; точный корень из рационального числа.
- 7 базовых размерностей СИ и их алгебра (`dimensions`).
- Реестр единиц с точными коэффициентами и родами величин (`units`); аффинная шкала °C.
- Роды, не конвертируемые друг в друга неявно: абсолютная температура / разность температур (`K_delta`, `degC_delta`), абсолютное / избыточное давление (`*_g`).
- Типизированные величины и явные мосты `temperatureDifference`, `shiftTemperature`, `gaugeToAbsolute`, `absoluteToGauge` (`quantity`).
- Фундаментальные константы с источником (`constants`): СИ 2019 (точные) и CODATA 2022 (со стандартной неопределённостью).
- Рекурсивно замороженные реестры.
- Неопределённости величин (`uncertainty`).

## Зарегистрированные производные единицы
Каждый род — отдельная явная таблица единиц с точными коэффициентами и обоснованием (`basis`):

| Род | Единицы |
|---|---|
| площадь | м², см², мм² |
| объём | м³, л, мл, см³, мм³ |
| скорость (в т. ч. осаждения/травления) | м/с, см/с, мм/с, мкм/с, нм/с, Å/с, нм/мин, мкм/мин, мкм/ч, км/ч |
| объёмный расход | м³/с, л/с, л/мин, см³/с, см³/мин, м³/ч |
| плотность тока | А/м², мА/см², мкА/см², А/см² |
| плотность мощности | Вт/м², кВт/м², мВт/см², Вт/см² |
| концентрация | м⁻³, см⁻³ |
| массовая плотность | кг/м³, г/см³ |
| частота | Гц, кГц, МГц, ГГц |
| электрический заряд | Кл, мКл, мкКл, А·ч |

### Свойства материалов (M1.3.0)
Роды и единицы для будущего реестра свойств (значений материалов здесь нет), все размерности выведены из базовых СИ, коэффициенты следуют из определений единиц:

| Род | Единицы |
|---|---|
| теплопроводность Вт/(м·К) | Вт/(м·К), мВт/(м·К), Вт/(см·К) |
| удельная теплоёмкость Дж/(кг·К) | Дж/(кг·К), кДж/(кг·К), Дж/(г·К) |
| КЛТР, К⁻¹ | К⁻¹, °C⁻¹, 10⁻⁶ К⁻¹ |
| электрическое сопротивление | Ом, мОм, кОм, МОм |
| удельное сопротивление | Ом·м, Ом·см, мкОм·см, нОм·м |
| удельная проводимость | См/м, См/см, МСм/м |
| молярная масса | кг/моль, г/моль |
| напряжённость магнитного поля H | А/м, кА/м |
| намагниченность M | А/м, кА/м, эме/см³ |
| модуль упругости | Па, МПа, ГПа (с суффиксом `_mod` в идентификаторе) |
| температуропроводность | м²/с, см²/с, мм²/с |

В M1.3.0 фактически добавлено **33 единицы** (11 родов).

Особенности:
- **Одинаковая размерность — разные величины.** Напряжённость поля H и намагниченность M (А/м) и модуль упругости (размерность давления) — отдельные роды: между ними нет неявной конвертации (`kind_mismatch`). Подробно — в разделе «Семантические роды» ниже.
- **КЛТР** — обратная величина ИНТЕРВАЛА температур: `°C⁻¹ = К⁻¹` без смещения 273,15. Определение коэффициента (касательный `α(T)` или средний от опорной температуры) единицей не задаётся и описывается в условиях свойства (M1.3.2).
- **Сопротивление.** Род `resistance` не ограничен по знаку (дифференциальное сопротивление может быть отрицательным), но это свойство общего рода, а не разрешение на отрицательное сопротивление произвольного пассивного омического элемента; проверку допустимости для конкретного объекта выполняет вызывающий код. Удельное сопротивление и проводимость материала неотрицательны.
- **Обратные величины:** переход удельное сопротивление ↔ проводимость — не конвертация единиц, а операция (`powerMeasured(ρ, -1)` даёт проводимость с неопределённостью).
- **Не включено:** твёрдость (универсального коэффициента между HV, HRC и др. шкалами нет; методы испытания будут описаны в M1.3.2); эрстед (1 Э = 1000/(4π) А/м — иррациональный коэффициент, не точная рациональная единица); sccm/slm.

`kindOfDimension` находит род результата произведения/частного/степени по размерности (В·А → мощность), **только если эту размерность имеет ровно один род**. Незарегистрированная (Дж/м: сила) или неоднозначная размерность — ошибка `unsupported_dimension`, не догадка.

**Универсального парсера произвольных составных единиц нет.** Единица — строго типизированный идентификатор из реестра; «Вт/(м²·К)» или «см³·торр/с» не разбираются из строки, новый род добавляется в `QUANTITY_KINDS` явно. **sccm/slm не включены**: они зависят от опорного состояния газа (T, p) — отдельное решение.

## Семантические роды
Размерность — не смысл. Несколько родов имеют одну размерность СИ, и ядро **никогда не подменяет один другим**:

| Размерность | Роды |
|---|---|
| К | абсолютная температура; разность (интервал) температур |
| Па (кг·м⁻¹·с⁻²) | абсолютное давление; избыточное давление; модуль упругости |
| А/м | напряжённость магнитного поля H; намагниченность M |

Правила (реализованы в `convert`, `kindOfDimension`, `uncertainty.ts`):
1. Между такими родами нет неявной конвертации (`kind_mismatch`): модуль упругости ≠ давление, H ≠ M, интервал ≠ абсолютная температура.
2. `kindOfDimension` для общей размерности отвечает `unsupported_dimension`: род результата произведения, частного или степени не определяется только размерностью. Поэтому результат с размерностью К, Па или А/м из произведения/частного/степени получить нельзя, в частности `powerMeasured(КЛТР, -1)` — **обратный КЛТР не является абсолютной температурой** (физически это интервал температур, но такой операции пока нет, возвращается контролируемая ошибка).
3. Семантический род (интервал температур, избыточное давление, H, M, модуль упругости) не может быть операндом произведения, частного и степени, кроме случаев, где смысл сохраняется доказуемо: умножение и деление на безразмерную величину (в том числе с неопределённостью), степень 1 (тождество) и степень 0 (константа 1), отношение двух величин одного рода (безразмерное). Масштабирование на точное число — `scaleMeasured`.
4. Абсолютная температура и абсолютное давление сохраняют свой род так же (умножение на безразмерную величину, степень 1); их произведение с другой величиной допустимо, если размерность результата однозначна (p·V → энергия).

Ограничение: алгебра размерностей поддерживает составные формулы (α·ΔT, C·ΔT, E·ε, R·A без промежуточной величины), но через `Measured` они пока исполнимы не всегда: нужный промежуточный род может быть не зарегистрирован (Ом·м²), а семантический операнд запрещён. Такие случаи дают контролируемую ошибку (`unsupported_dimension` или `kind_mismatch`), а не результат неверного рода. Пример исполнимой формулы: ρ = R·(A/L).

## Неопределённости
- **Стандартная неопределённость** `u` (одно стандартное отклонение, k = 1) хранится в `Measured` в той же единице, что и значение; `u ≥ 0`. Пересчёт единиц масштабирует `u` только множителем (смещение °C в неопределённость не входит).
- **Расширенная неопределённость** `U = k·u` — только вычисляемая величина (`expandedUncertainty(m, k)`, k > 0); в `Measured` не хранится. Распределение не предполагается: k = 2 соответствует ≈95 % только для нормального распределения.

### Модель независимых входных величин
Все формулы (сумма, разность, произведение, частное, степень) — это формулы GUM **для независимых (некоррелированных) входов**. Явно:
- **Корреляции не поддерживаются**: нет ковариаций, идентификаторов источников погрешности и способа задать корреляцию.
- Бинарные функции `addMeasured`, `subtractMeasured`, `multiplyMeasured`, `divideMeasured` (и `temperatureDifferenceMeasured`) отказывают с кодом `correlated_inputs`, если в обоих аргументах передан **один и тот же объект** `Measured` (`x + x`, `x - x`, `x * x`, `x / x`) — это единственный случай, который виден наверняка. Для возведения в квадрат и удвоения используйте `powerMeasured(x, 2)` и `scaleMeasured(x, 2)`.
- Проверка `a === b` — **не обнаружение корреляций**. Копия объекта, два результата одного измерения или величины с общим источником погрешности принимаются и обрабатываются как независимые (например, `x − копия(x)` даст √2·u вместо точного 0). Ответственность за независимость лежит на вызывающем коде.
- Для коррелированных величин нужна общая формула GUM с ковариационными членами (не реализована).

### Ограничения линейного распространения первого порядка
Результат — разложение (линеаризация) функции первого порядка в точке значений входов. Сложение, вычитание и масштабирование на точный коэффициент линейны (аффинны) по входным величинам, как и степень `n = 1`: для независимых входов формула для них не содержит приближения. Произведение, частное и степень `|n| ≥ 2` нелинейны, и для них приближение первого порядка может оказаться недостаточным — особенно когда неопределённость входа существенна относительно масштаба нелинейности (для частного — относительно расстояния от значения знаменателя до нуля; для произведения — когда не пренебрежимо `u(a)·u(b)` по сравнению с остальными вкладами). Большая относительная неопределённость сама по себе не делает результат автоматически неверным, и модуль не оценивает достаточность приближения — об этом результат ничего не сообщает. Дополнительно обнаруживается и **отклоняется** (код `degenerate_linearization`) один подтверждённый математически случай — когда все коэффициенты чувствительности первого порядка равны нулю при неопределённом входе, и формула дала бы формальный ноль для неточно известного результата:
- `powerMeasured(x, n)` при `x = 0`, `|n| ≥ 2`, `u(x) > 0` (y = xⁿ в стационарной точке; `powerMeasured(measured(0, 1, 'm'), 2)`);
- `multiplyMeasured(a, b)` при `a = 0` и `b = 0`, обе с `u > 0`.

Это **не** запрет нулевых входов: при `u = 0` (результат известен точно), для линейных операций (`n = 1`, сумма, разность, масштабирование), для частного (коэффициент числителя `1/|b|` не обращается в 0; само частное остаётся нелинейным, и при существенной `u(b)` приближение первого порядка может быть недостаточным) и при ненулевом партнёре в произведении результат возвращается. Поправка второго порядка и методы высших порядков не вводятся; близкие к вырождению (но не нулевые) входы не диагностируются — порога нет.

### Политика overflow и underflow
Значения и все вклады в неопределённость считаются точно (рационально); округление — один раз в конце. Нет промежуточных `number`-произведений, квадратов и степеней, поэтому представимый результат возвращается и при экстремальных промежуточных выражениях (1e200·1e198). Результат, который не помещается в double, — `overflow`; ненулевой результат (в том числе ненулевая неопределённость), который стал бы нулём или субнормальным числом, — `underflow`. Ненулевая неопределённость никогда не заменяется нулём; ноль возвращается только когда он точный.

### Перспектива (не реализовано)
- Ковариации и общая формула GUM для коррелированных входов; идентификаторы источников погрешности.
- Метод Монте-Карло (GUM Supplement 1) для нелинейных функций и больших относительных неопределённостей.
- Поправки второго порядка.

## Прочие ограничения
- Избыточное давление переводится в абсолютное только с явно заданным опорным давлением; значения по умолчанию (101325 Па) нет.
- Число `number` берётся как кратчайшая десятичная запись (то, что ввёл пользователь).
- Нет реестра материалов, моделей PVD/CVD/ALD и магнетрона — это отдельные этапы.
- Существующий калькулятор по-прежнему использует торр = 133.322 Па; новое ядро — точный 101325/760 Па. Миграция — отдельный этап.

## Принятые решения для будущего реестра материалов (M1.3)
Фиксируются здесь как ограничения; в M1.3.0 они не реализуются.
1. Реестр материалов будет находиться в `src/materials/`, отдельно от физического ядра (ядро не зависит от него).
2. Агрегатное состояние (фаза) и микроструктура — разные сущности.
3. Массивные материалы, мишени и тонкие плёнки автоматически не эквивалентны: свойство принадлежит варианту (материал + фаза + форма), подстановка одного вместо другого — только явной записью с источником.
4. Неизвестная неопределённость не равна нулевой (`u = 0` в `Measured` означает «известно точно»).
5. Номинальный расчёт допустим при неизвестной неопределённости, но оценка неопределённости результата требует достаточной информации и без неё не выдаётся.
6. Литературные значения с разными условиями измерения не считаются автоматически противоречащими; конфликт определяется только при сравнимых условиях.
7. Автоматическое усреднение литературных значений не допускается.
8. Многослойные системы поддерживают повторяющиеся пакеты и последовательности слоёв.
9. Экстраполяция свойств вне проверенного диапазона в первой версии запрещена.
10. Данные пользователя и поставляемые справочные сведения хранятся раздельно.
