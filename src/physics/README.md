# `src/physics` — физическое ядро (Stage 6 / M1.1)

Без зависимостей, детерминированное, не подключено к существующим калькуляторам, TechDoc, TEA и Equipment Selector.

## Что есть
- точная рациональная арифметика на BigInt (`exact`), одно округление в конце;
- 7 базовых размерностей СИ и их алгебра (`dimensions`);
- реестр единиц с точными коэффициентами и родами величин (`units`); аффинная шкала °C;
- роды, не конвертируемые друг в друга неявно: абсолютная температура / разность температур (`K_delta`, `degC_delta`), абсолютное / избыточное давление (`*_g`);
- типизированные величины и явные мосты `temperatureDifference`, `shiftTemperature`, `gaugeToAbsolute`, `absoluteToGauge` (`quantity`);
- фундаментальные константы с источником (`constants`): СИ 2019 (точные) и CODATA 2022 (с неопределённостью);
- реестры заморожены (`Object.freeze` рекурсивно).

## Ограничения текущей реализации
- **Нет составных единиц** (м³/с, sccm, Вт/(м²·К), Дж/К...). Реестр содержит только перечисленные единицы; составные константы имеют только текстовый символ `siSymbol`.
- **Нет универсального парсера** выражений единиц. Единица — строго типизированный идентификатор (`UnitId`).
- Нет неопределённостей у величин, реестра материалов, моделей PVD/CVD/ALD и магнетрона — это отдельные этапы.
- Избыточное давление переводится в абсолютное только с явно заданным опорным давлением; значения по умолчанию (101325 Па) нет.
- Число `number` берётся как кратчайшая десятичная запись (то, что ввёл пользователь); результат — ближайший `number` к точному значению. Результат, который не помещается в double или стал бы нулём/субнормальным, — ошибка, а не «0».
- Список единиц ограничен задачами M1.1; новые единицы добавляются в `UNITS` вместе с обоснованием коэффициента (`basis`).
- Существующий калькулятор по-прежнему использует торр = 133.322 Па; новое ядро — точный 101325/760 Па. Миграция — отдельный этап.
