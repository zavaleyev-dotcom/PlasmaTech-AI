## Ограничения

Метаданные PDF отражают заполненные в документе поля, которые могут быть неточными.
OCR, внешнее обогащение, AI-анализ, RAG, embeddings и vector database не выполняются.
Для этой локальной версии нужен работающий Node.js/Next.js процесс на 127.0.0.1.
Остановка процесса прерывает текущее обновление; прежний индекс остаётся доступным.
Подробности: `docs/architecture.md`, раздел «Моя библиотека — локальный индекс PDF».
