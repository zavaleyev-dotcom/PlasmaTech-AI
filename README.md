# PlasmaTech-AI
AI platform for vacuum-plasma technologies, scientific research and engineering tools

## Локальная разработка

Платформа на Next.js (App Router), TypeScript и Tailwind CSS.

```bash
npm install
npm run dev
```

Адрес: http://127.0.0.1:3000

```bash
npm run lint
npm run typecheck
npm run build
npm start
```

## Структура

- `src/app` — главная, маршруты семи разделов, метаданные и стили.
- `src/components` — навигация, карточки, демо-диалоги и графика.
- `src/lib/content.ts` — описания инструментов и демонстрационные сценарии.
- `src/lib/demo-provider.ts` — интерфейс провайдера и локальная демо-реализация.

SciFinder выполняет реальный библиографический поиск через серверный API и Crossref. Остальные пять инструментов возвращают фиксированные учебные примеры. Запросы не сохраняются в базе данных. Контакты и биография ожидают заполнения владельцем; проекты обозначены как концепции.

## Будущие интеграции

Интерфейс `WorkspaceProvider` отделяет сценарии от интерфейса. Реальную реализацию следует подключать через серверные Next.js Route Handlers. OpenAI API, Supabase, Google Drive, MCP, авторизация и платежи сейчас не подключены. Секреты будущих интеграций хранить только в серверных переменных окружения (не `NEXT_PUBLIC_*`). Для внешних источников добавить отдельные серверные адаптеры; не вызывать их напрямую из клиентских компонентов.

## Следующий этап архитектуры

У каждого из шести инструментов есть отдельная страница `/workspace/<module>`.
Карточка SciFinder открывает поисковую страницу напрямую. Для остальных инструментов
сохранён демо-диалог со ссылкой на страницу, полем задачи и учебным результатом.

Определения модулей находятся в `src/modules/workspace`, сервис — в
`src/services/workspace`. Добавлены контракты для `agents`, `skills`, `database`,
`integrations`, `calculators` и `knowledge-base`. Из внешних источников включён
только публичный Crossref REST API. Маршруты, границы слоёв и порядок будущего подключения описаны в
[docs/architecture.md](docs/architecture.md).


## SciFinder: реальный библиографический поиск

Страница: http://127.0.0.1:3000/workspace/scifinder

Crossref работает без API-ключа. Браузер отправляет `POST /api/scifinder/search`;
только сервер Next.js обращается к `https://api.crossref.org/`. Поиск поддерживает
тему, ключевые слова, точный DOI (включая DOI-ссылку), годы, тип публикации,
наличие DOI/abstract и выборку 10/25/50 результатов. При введённом DOI тема
и ключевые слова игнорируются, а фильтры продолжают действовать.

Для необязательных настроек скопируйте `.env.example` в `.env.local`:

- `CROSSREF_CONTACT_EMAIL`: реальный контакт для polite pool Crossref, необязателен.
- `OPENALEX_API_KEY`: резерв для следующего этапа. Даже при наличии ключа адаптер
  OpenAlex пока не активирован и не делает запросов. Не используйте `NEXT_PUBLIC_`.

Перезапустите сервер после изменения переменных. Реальные ключи не коммитить:
`.env.local` исключён из Git; в `.env.example` только пустые значения.

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm start
```

Тесты не обращаются к внешним API. Они проверяют нормализацию, DOI lookup,
дедупликацию, фильтры, валидацию маршрута, тайм-аут и ошибки источника.
Для ручной проверки заполните пример `AlTiSiN coating cutting tools`, выполните
поиск, затем вставьте DOI одной из найденных публикаций в поле точного поиска.

Показывается первая выборка, а не полный экспорт Crossref. Счётчик отдельно
отображает совпадения источника, загруженные записи и результат после фильтрации.
Abstract — текст из метаданных, без AI-обработки; он может отсутствовать.
Тип `journal-article` не используется как признак рецензирования. Статус open access
для Crossref неизвестен (`null`), лицензии не интерпретируются как доказательство OA.
Полные тексты и PDF не скачиваются.
